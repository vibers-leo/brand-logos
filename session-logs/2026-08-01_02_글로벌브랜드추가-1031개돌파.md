# 2026-08-01 (2차) — Simple Icons 글로벌 브랜드 34개 추가, 1,031개 돌파

## 세션 개요
- 프로젝트: brand-logos (logo.vibers.co.kr)
- 핵심 결과: 997개 → **1,031개** (1,000개 돌파)
- Simple Icons CDN 기반 글로벌 인기 브랜드 34개 수집

## 주요 작업

### 1. Wikimedia / Brandfetch 가능성 조사

**Wikimedia:** 추가 수집 가능 카테고리 탐색 결과 SVG가 거의 없음
- schools in South Korea: 34개 파일, SVG 0개 (PNG/WebP 위주)
- political parties in South Korea: 40개 파일, SVG 1개만
- 글로벌 카테고리 "SVG logos of technology companies": 500개 파일이지만 알 수 없는 소기업 위주
- **결론:** Wikimedia는 한국 브랜드 SVG 더 이상 수집 한계

**Brandfetch:** API 키 필수 (401), 무료 플랜 없음 → 보류

### 2. Simple Icons CDN 글로벌 브랜드 수집

Wikimedia/FA가 커버하지 못하는 글로벌 유명 브랜드를 Simple Icons CDN(`cdn.simpleicons.org/{slug}`)으로 직접 수집.

**SI_GLOBAL_TARGETS (34개) 추가:**
- 스포츠: nike, adidas, puma, newbalance, underarmour
- 식음료: mcdonalds, burgerking, kfc, cocacola
- 미디어/스트리밍: netflix, hbo, cnn, nbc, fox
- 자동차: tesla, toyota, bmw, volkswagen, honda, ford
- 반도체/IT: intel, nvidia, qualcomm
- 협업/SaaS: zoom, webex, sap, hubspot
- 여행: expedia, tripadvisor
- 배달/모빌리티: lyft, doordash
- 리테일/패션: target, zara, uniqlo

**collect_si_global() 함수 추가** (`collect-auto.py`)
- CLI: `python3 collect-auto.py --source si-global`
- CDN에서 SVG → `logo.svg` + `sources/si.svg` 동시 저장
- label: "컬러 심볼"

### 3. sources 소급 적용 버그 수정

`add_existing_sources`에서 logo.dev 감지 prefix 오탐 수정:
- 버그: `startswith("logodev:")` (점 없음)
- 수정: `startswith("logo.dev:")` (점 있음)
- 결과: 915개 브랜드 sources 재적용 완료

### 4. PNG 파이프라인

34개 신규 SI 브랜드 모두 cairosvg로 400×400 PNG 생성 완료.
`brands.json` `logo_png` 필드 전체 동기화 실행.
