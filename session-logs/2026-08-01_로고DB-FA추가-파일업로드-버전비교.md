# 2026-08-01 — 로고창고 FA brands 추가 + 파일 업로드 + 버전 비교 UI

## 세션 개요
- 프로젝트: brand-logos (logo.vibers.co.kr)
- 핵심 결과: 937개 → **997개** 브랜드, 버전 비교 기능 추가, AI/PDF 업로드 파이프라인 구축

## 주요 작업

### 1. 2차 logo.dev 수집 (+235개)
- KR_DOMAINS에 스트리밍/뷰티/식품/제약/교육/물류/글로벌 브랜드 300여 도메인 추가
- 실제 수집: 692 → 927개
- Wikimedia 추가 카테고리: TV채널/병원 +10개 → 937개

### 2. AI/PDF 파일 업로드 파이프라인
- **NCP 서버 Inkscape 설치** (1.2.2 Ubuntu apt)
- **logo-convert Flask API** (`/root/scripts/logo-convert-server.py`, 포트 9201, systemd 상시실행)
  - `POST /convert` → bucket 다운로드 → Inkscape AI/PDF/EPS → SVG → bucket 재업로드
- **ai.vibers.co.kr/api/logo-submit 업그레이드**
  - multipart/form-data 수신 (AI/PDF/EPS/SVG/PNG, 최대 30MB)
  - NCP vibers-bucket `brand-logos/originals/{id}/{filename}` 저장
  - Firestore에 bucket_key, bucket_url, file_ext 저장
  - AI/PDF/EPS 시 NCP 변환 자동 트리거
- **index.html 제보 폼 업그레이드**
  - 파일 드래그앤드롭 UI + 업로드 진행 표시
  - 원본 다운로드 버튼 (brands.json의 original_url 필드 기반)

### 3. Font Awesome brands 수집 + 버전 비교 UI
- **collect-auto.py에 FA 수집 모듈 추가**
  - FA_TARGETS: 69개 대상 (소셜/결제/테크/게임/스트리밍 등)
  - `sources/fa.svg` 폴더에 별도 저장 (기존 logo.svg 덮어쓰지 않음)
  - brands.json `sources` 필드에 `{"provider":"font-awesome","file":"sources/fa.svg","label":"아이콘형"}` 추가
- **sources 소급 적용** (`--source sources`): 921개 브랜드에 출처 필드 부여
  - logo.dev → `실물형`, Wikimedia → `공식 SVG`, Simple Icons → `컬러 심볼`, FA → `아이콘형`
- **FA 수집 결과**: 기존 6개 업데이트 + 신규 60개 추가 → **997개 총계**
- **index.html 버전 비교 패널**
  - 카드 확장 시 `sources` 2개 이상이면 "버전 비교" 그리드 표시
  - 클릭 시 URL 클립보드 복사 + 토스트 알림 (`pickSource` 함수)
  - 출처명 대신 스타일명 표기 (아이콘형/컬러 심볼/실물형/공식 SVG)

### brands.json sources 구조
```json

  "sources": [
    {"provider": "logo.dev", "file": "logo.png", "label": "실물형"},
    {"provider": "font-awesome", "file": "sources/fa.svg", "label": "아이콘형"}
  ]
}
```
